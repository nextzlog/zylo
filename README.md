ZyLO
====

![image](https://img.shields.io/badge/license-MIT-darkblue.svg)
![badge](https://github.com/nextzlog/zylo/actions/workflows/build.yaml/badge.svg)
![badge](https://github.com/nextzlog/zylo/actions/workflows/clean.yaml/badge.svg)

ZyLO is the plugin interface of [zLog 令和 edition](https://use.zlog.org) and [zLog Max](https://max.zlog.org).
zLog loads plugins that export the [ZyLO functions](https://nextzlog.github.io/zylo), and users install them with the plugin manager dialog.
